# 🧪 QA Web Automation – Cypress + BDD

Projeto de automação de testes web desenvolvido para demonstrar boas práticas de **Qualidade de Software (QA)**, utilizando **Cypress**, **JavaScript** e **BDD (Gherkin)**.

Este repositório faz parte do meu portfólio profissional como Analista de Testes (QA).

---

## 🎯 Objetivo

Demonstrar a criação de testes automatizados para aplicações web, cobrindo fluxos funcionais críticos, com foco em:
- Legibilidade dos testes
- Organização do projeto
- Manutenibilidade
- Colaboração com equipes de desenvolvimento

---

## 🛠️ Tecnologias Utilizadas

- Cypress
- JavaScript
- BDD (Cucumber / Gherkin)
- Node.js
- GitHub
