Projeto de automação de testes web desenvolvido para demonstrar boas práticas de **Qualidade de Software (QA)**, utilizando **Cypress**, **JavaScript** e **BDD (Gherkin)**.

Este repositório faz parte do meu **portfólio profissional** como Analista de Testes (QA).

---

## 🎯 Objetivo

Demonstrar a criação de testes automatizados para aplicações web, com foco em:

- Legibilidade (cenários BDD claros)
- Organização do projeto
- Manutenibilidade (Page Objects/Commands, reutilização)
- Execução em pipeline (CI)
- Boas práticas de validação e evidências

---

## 🧩 Escopo dos testes

- Fluxos funcionais críticos (ex.: login, compra, validações de campos)
- Cenários BDD no formato **Gherkin**
- Evidências via screenshots (em falhas)
- Execução local e em **CI (GitHub Actions)**

> 💡 Dica: se você quiser, depois a gente coloca: tags (@smoke, @regression), relatórios (Mochawesome/Allure) e publicação de artefatos no GitHub Pages.

---

## 🛠️ Tecnologias utilizadas

- **Cypress**

- **Cucumber (plugin para Cypress)**
